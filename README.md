# AWS VPC Project – Public and Private Subnets

## Overview

This project demonstrates the implementation of an AWS Virtual Private Cloud (VPC) with public and private subnets, routing, internet connectivity, and network security controls.

The project is based on the hands-on AWS project tutorial by Abhishek Veeramalla.

## Objectives

- Create a custom AWS VPC.
- Configure public and private subnets.
- Set up an Internet Gateway and NAT Gateway.
- Configure route tables and subnet routing.
- Deploy EC2 instances within the VPC.
- Configure Security Groups and Network ACLs.
- Understand network isolation and internet connectivity.

## AWS Services Used

- Amazon VPC
- Amazon EC2
- Internet Gateway
- NAT Gateway
- Route Tables
- Security Groups
- Network ACLs
- IAM, where required

## Architecture

The architecture separates public-facing resources from private resources and uses routing and security controls to manage network traffic.
